# Первые кадры открытия меню

Воспроизведён отдельный дефект: native dialog автоматически фокусировал первый пункт меню, находящийся в анимируемой панели за правым краем. Контейнер с overflow:hidden оставался программно прокручиваемым. Его scrollLeft в момент открытия достигал 375 px на viewport 390 px и 420 px на viewport 1024 px. Браузер затем возвращал scrollLeft к нулю, мешая анимации панели.

Исправление: до showModal единственная кнопка бургера получает autofocus; при возврате в шапку атрибут удаляется. Внешний контейнер меню использует overflow:clip — анимируемая панель обрезается без создания дополнительной области прокрутки. Внутренняя панель сохраняет собственную вертикальную прокрутку.

`node tests/menu-opening.cjs` проверяет первые 600 мс синхронно после открытия и затем на каждом requestAnimationFrame, с видимыми системными scrollbar. Viewport 320, 390, 768, 1024 px; исходный scrollY 0 и 1200. Во всех восьми случаях scrollLeft/scrollTop внешнего меню остаются нулевыми; координаты кнопки, высота документа и scrollY стабильны. Панель плавно движется от правого края к открытому положению. Замеры: menu-opening-frames.json.

Также повторно пройдены проверки menu-toggle, menu-scrollbar и revision-interactions. Исправление предыдущего дефекта с появлением вертикальной полосы сохранено. Проверка — Chromium, без проверки физических iOS-устройств.
