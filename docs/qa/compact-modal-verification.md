# Компактные модальные окна на мобильных

Правки ограничены viewport до 700 px и не затрагивают меню. Убраны дублирующие внутренние отступы формы, сокращены вертикальные промежутки и отступы окна. Заголовок 26 px; текст полей остаётся 16 px, фактическая высота полей около 47,6 px. Поля расположены в одну колонку.

При высоте viewport 800 px окно консультации изменилось: ширина 320 px — с 764,7 до 613,6 px; 390 px — с 685,7 до 592,6 px; 430 px — с 661,7 до 522,3 px. Скриншот: modal-mobile-after.png.

На 320×480 проверены окно с данными калькулятора, доступность кнопки отправки через внутреннюю прокрутку, сообщения валидации, отсутствие горизонтального переполнения и закрытие по Escape. Пройдены phone-mask.cjs и extended.cjs. Папка dist обновлена.
